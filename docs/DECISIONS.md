## Current integration and acceptance boundary — 8 October 2026

- Steps 14–19 are source-implemented; Firebase/Auth/server authorization, emulator acceptance, Rules/index deployment, reviewed migration execution, and authenticated empty-app inspection remain pending.
- Steps 21–24 are accepted only within their recorded scopes. Step 22 callback probes lacked authentication headers; the pinned release documents `cron.webhookToken`, whose configured secret handling and delivery remain untested.
- The Rex deployment manifest verifies a runtime identity mapping. It is not an owner-scoped application mapping. No authenticated report receiver, generalized app report path, or persisted live app report exists; recurring research remains disabled.
- The next implementation gate is Step 20 host-specific closeout followed by C1 Firebase environment activation, as listed in the [technical guide](../Investment%20Office%20Technical%20Implementation%20Guide.md#current-acceptance-ledger--8-october-2026) and [`docs/PROGRESS.md`](./PROGRESS.md).

The official Node release page lists Node 26.10.0 as Current and 24.21.0 as LTS as of this baseline. The package engine range permits Node 24.x for Vercel builds and Node 26.x locally for the planned OpenClaw runtime. See [Node.js releases](https://nodejs.org/en/about/previous-releases).

The selected Vite 8 line supports Node 20.19+ and 22.12+; this project pins Node 26 per the guide. See the [Vite 8 release notes](https://vite.dev/blog/announcing-vite8).
